Le Processus en 7 Étapes (100% Réproducible)
Étape 1 : Template de base (copie-colle toujours ça)
Python"""
NOM_DU_SERVEUR - MCP Server
"""
from fastmcp import FastMCP
import logging

# Logger
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

# Instance MCP (CHANGE UNIQUEMENT LE NOM)
mcp = FastMCP(name="TON_NOM_UNIQUE")  # ex: "DatabaseMCP", "ImageMCP"

# === TES OUTILS ===
@mcp.tool()
def ton_premier_outil(param: str) -> dict:
    """Description de l'outil pour Gemini"""
    return {"result": f"Tu as appelé {param}"}

@mcp.tool()
def get_stats() -> dict:
    """Statistiques du serveur"""
    return {"status": "✅ Running"}

# === DÉMARRAGE (NE JAMAIS CHANGER CETTE PARTIE) ===
if __name__ == "__main__":
    logger.info("🚀 Démarrage du serveur MCP")
    mcp.run(
        transport="http",
        host="0.0.0.0",
        port=8080,           # ou 8081, 8082... pour plusieurs serveurs
        path="/mcp"          # IMPORTANT : toujours "/mcp"
    )

Étape 6 : Configuration Gemini Code Assist
Fichier : ~/.gemini/settings.json (ou dans Cursor/Continue)
JSON{
  "mcpServers": {
    "ton-serveur-mcp": {
      "httpUrl": "http://127.0.0.1:8080/mcp/",
      "timeout": 360000,
      "trust": true
    }
  }
}
Points critiques :

http://127.0.0.1:8080/mcp/ ← le slash final / est OBLIGATOIRE
path="/mcp" dans mcp.run() ← doit correspondre
Port différent = URL différente
